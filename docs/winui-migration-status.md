# SnipIt WinUI 기존 동작 복원 검증 — 2026-09-12

현재 버전은 2.7.0-preview.2입니다. 기존 WPF 사용 흐름을 복원하고 검증한 프리뷰이며, 정식 릴리즈 및 자동 업데이트 배포는 진행하지 않았습니다.

## 수정된 동작

- 연속 캡처는 열린 편집기 한 개를 재사용합니다. 새 이미지로 교체할 때 원본, 실행 취소 상태, 이력 선택을 갱신하고 마지막 편집 도구를 유지합니다.
- 캡처 전에 메인/편집기를 숨기고 취소 또는 실패 시 편집기를 복원합니다. 최근 캡처 편집은 메모리 이미지가 없으면 저장된 최신 이력을 엽니다.
- 미저장 편집은 전환 확인으로 보호합니다. 전환을 거절해도 새 캡처 원본은 이력에 남습니다. 빠른 이력 연속 선택은 마지막 선택만 반영합니다.
- 기존 순서의 도구 툴바, 빠른 색상 6개, 사용자 지정 색상, 글꼴 9종, 이미지 위 텍스트 입력을 복원했습니다. 편집 후 자동 복사 설정을 적용하고 Esc는 편집기를 닫습니다. OCR 중 Esc는 OCR만 종료합니다.
- OCR은 이미지 위 단어 선택, Ctrl 추가 선택, 여러 줄 드래그 선택과 복사를 지원합니다. 이미지 전환 시 이전 인식 결과를 제거합니다.
- GIF는 3초 준비 시간, 영역 바깥 테두리, 취소/정지/저장 및 자원 정리를 지원합니다. 제어창 캡처 제외 실패 시 안내합니다.
- 설정은 일반/GIF/전역 단축키/에디터 단축키 페이지로 구성했습니다. 취소는 실설정을 변경하지 않으며 저장 성공 후 적용합니다. 기본값 복원, 폴더 선택 및 영어 표시를 연결했습니다.
- 영역 캡처에서 방향키 1픽셀, Shift+방향키 10픽셀, Space 시작/확정, Enter 확정, Esc 취소를 지원합니다. 분수 DPI에서 정수 픽셀 경계의 부동소수점 오차를 보정했습니다.

미저장 편집 보호 및 명령 기반 실행 취소처럼 의도적인 개선도 있으므로 기존 내부 구현과 완전히 동일하다는 의미는 아닙니다.
