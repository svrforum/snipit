# SnipIt v2.6.1 성능 검증

2026-09-08, Windows / Intel Core Ultra X7 358H / 논리 프로세서 16개 / .NET 9 Release x64.
기준은 v2.6.0 소스, 변경 후는 로컬 v2.6.1입니다. 아래 수치는 한 장치의 단회 측정이며 일반 성능 보장이나 장시간 누수 부재 증명이 아닙니다.

## 적용한 변경

- 세로 썸네일을 가로 480 / 세로 300 안에 디코딩: 작은 PNG를 다시 크게 확대하던 문제 수정.
- 이력 목록은 가상화된 행이 썸네일을 요청할 때 비동기 로딩. 이력 전체를 먼저 디코딩하지 않음.
- 서비스 썸네일 캐시는 최근 32개로 제한. 최대 픽셀 버퍼 약 17.6MiB이며, 열린 화면이 참조하는 이미지와 WPF 오버헤드는 별도.
- 편집기 종료 시 원본 표시 소스, 그리기 요소, 이력 목록 참조 해제.
- GIF에 저장할 프레임은 원시 픽셀만 복사해서 GDI 그리기용 버퍼를 보관하지 않음. 중복/한도 초과 프레임은 먼저 제외.
- GIF 프레임 메모리 계산은 실제 픽셀 형식과 stride를 반영.

## 비교 결과

| 시나리오 | v2.6.0 | 변경 후 |
|---|---:|---:|
| 200×4000 세로 캡처 100장, 전체 썸네일 픽셀 데이터 | 305.2MiB | 1.72MiB |
| 같은 썸네일 최초 디코딩 | 400.4ms | 53.6ms |
| 해당 단계 프로세스 전용 메모리 | 398.1MiB | 101.0MiB |
| 1280×720 실제 캡처 90장 보관, GIF 원본 모드 | 567.5MiB | 250.5MiB |
| 위 GIF 취소 직후 전용 메모리 | 12.5MiB | 12.6MiB |
| 위 GIF 전체 처리 경과 시간 | 1553ms | 1539ms |
| 위 GIF CPU 누적 시간 | 484ms | 563ms |

GIF 메모리는 약 56% 감소했습니다. 새 프레임을 분리하는 복사 때문에 이 테스트의 CPU 시간은 약 16% 늘었습니다. 실행 시간 차이는 측정 변동 범위로 해석하며 속도가 개선됐다고 주장하지 않습니다.

캐시가 32개로 제한되므로 100개 전체를 반복 순회하면 다시 디코딩할 수 있습니다. 이 인위적 순회는 기존 0.013ms에서 약 4.88ms/회로 늘었습니다. 실제 화면은 보이는 행만 요청하며 메모리 상한을 우선한 절충입니다.

## 다른 시나리오

- 4K 단색 PNG 저장 10회: 125.6 → 121.9ms/장. 재열기 15.6 → 14.9ms/장. 단색 이미지는 일반 사진보다 압축 비용이 낮을 수 있습니다. 해당 경로에 속도 개선을 주장하지 않습니다.
- 4K 편집기 undo 15회 생성 후 닫기, 총 5회: 47.3 → 43.5ms/회. 전체 사용자 편집 동작을 자동 조작한 테스트가 아닌 메모리 상태 스택 스트레스입니다.
- 실제 화면 전체 캡처 30회: 67.4 → 58.4ms/장. 화면 구성/시스템 부하가 달라 인과적인 개선 수치로 사용하지 않습니다. 픽셀은 즉시 폐기했습니다.
- 트레이 대기: 업데이트 네트워크 확인을 끈 격리 프로필에서 8초 준비 후 30초 측정. 전용 메모리 92.6 → 92.5MiB, 작업 집합 약 158.6MiB, CPU 시간 증가 0ms(측정 해상도 이내).
- 정적 1080p GIF 1800프레임: 1프레임 유지, 1799프레임 병합. 이는 30fps 60초 분량을 빠르게 투입한 테스트입니다.
- 실제 720p 60초 GIF: 변경 후 프레임 8개 유지, 1786개 병합, 전용 메모리 약 33MiB, CPU 누적 10초(16 논리 CPU 전체 기준 평균 약 1.04%). 화면이 거의 정적이었습니다. 변경 전에는 화면 변화가 더 많아 97프레임과 약 610MiB에 도달했으므로 두 실시간 실행을 직접 성능 비교에 사용하지 않습니다.
- 움직이는 장면이 많으면 GIF 메모리 한도에 더 빨리 도달합니다. 무제한 장시간 녹화를 지원하는 구조로 바꾸지는 않았습니다.

## 검증 범위와 파일

회귀 테스트 통과: 세로 썸네일 상한, 캐시 제거, 원본 PNG 픽셀 보존, GIF 행 패딩/색상 보존, GIF 인코딩·재열기, undo/redo, 업데이트 검증 포함.
사용자 설정/캡처 이력은 변경하지 않았습니다. 실제 화면을 읽은 측정은 이미지 파일로 저장하지 않았습니다. 테스트용 프로세스만 종료했습니다.

측정 JSON: performance-before.json, performance-after.json, performance-idle.json, performance-live-gif.json, performance-live-gif-after.json, gif-memory-before.json, gif-memory-final.json.
