# v2.7.0 — WPF와 WinUI 함께 제공

- **SnipIt.exe**: 기존 WPF 버전. 기존 사용 흐름을 유지하려는 사용자에게 권장합니다.
- **SnipIt-WinUI.exe**: WinUI 버전. 컴팩트 화면, 편집기 재사용, 편집본 이력 자동 저장, 트레이 종료 동작을 제공합니다. 실제 혼합 DPI 다중 모니터와 장시간 성능 비교는 추가 검증 중입니다.

두 버전 모두 형광펜 수평 보정과 Shift 수평 고정을 지원합니다. WinUI 형광펜은 사각형 채우기에서 자유 곡선으로 변경했습니다.

## 업데이트
WPF는 SnipIt.exe, WinUI는 SnipIt-WinUI.exe만 선택하고 SHA256SUMS.txt의 해당 파일 체크섬을 검증합니다. WinUI 업데이트 캐시는 WPF와 분리했습니다. 업데이트 다운로드 후 앱에서 설치/재시작합니다.

이전 WinUI 프리뷰는 WPF용 파일을 선택하는 구형 업데이트 로직이 있으므로 이번 WinUI 파일을 직접 내려받아 교체하세요. 이후부터는 WinUI 전용 업데이트를 사용합니다. 두 프로그램을 동시에 실행하면 전역 단축키가 충돌할 수 있습니다.

## 검증
편집 코어 및 WPF 회귀 검사, 로컬 WinUI 통합 검사를 수행했습니다. CI에서도 회귀 검사 통과 후 두 파일을 빌드합니다. 코드 서명 및 VirusTotal 검사는 수행하지 않았습니다.
